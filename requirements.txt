# Narration (§18). Optional at runtime — `narrate()` falls back to
# `render_table`, which needs no network, no key and no model and states the
# same attribution record. The default backend is a LOCAL model over Ollama
# (no package needed, plain HTTP via httpx); `anthropic` is only the hosted
# fallback. Listed because strategy.yaml ships `narration.enabled: true`, so an
# absent package is a silent downgrade rather than a chosen one.
anthropic
